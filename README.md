# DiskHeatMap

Windows用のディスク使用量ヒートマップです。容量の大きい場所を面積で確認し、フォルダーへ潜ったり、その場で枠を分割したりできます。日本語UI・オフライン動作。

**[最新版をダウンロード](https://github.com/mezon-web/DiskHeatMap-Releases/releases/latest)**

![DiskHeatMapの画面例。動画フォルダーを選ぶと、右に動画の内訳が表示されます。](images/overview.png)

画面はすべて架空データです。

## 使い始める

1. Windows 11 x64で、**.NET 10 Desktop Runtime x64**を用意します。[Microsoftのダウンロードページ](https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0) の「.NET Desktop Runtime」を選んでください。
2. [Releases](https://github.com/mezon-web/DiskHeatMap-Releases/releases) の `DiskHeatMap-v0.1.0-win-x64.zip` をダウンロードして展開します。
3. `DiskHeatMap.exe` を起動し、フォルダーやドライブを選んで「スキャン」。エクスプローラーからフォルダーまたはドライブ1件をドロップしても開始できます。

ランタイム非同梱の単一EXEです。ZIPには日本語の「使い方.txt」と、画像を内蔵したオフラインの「使い方.html」が入っています。インストーラーや常駐サービスはありません。

## できること

- マップで容量の割合を確認。大きいほど暖色で表示します。
- クリックで選択、右の内訳で直下のフォルダー・ファイルを確認。補足は「詳細」を開きます。
- 「中を見る」で階層移動、「分割」で選んだ枠の中だけ展開。ダブルクリックの動作も切り替え可能。
- パンくず・戻る／進む・マウスのサイドボタンで移動し、選択・分割・内訳の対象を復元。
- 空き領域の表示切替、ディスク上のサイズ／通常のファイルサイズ切替、名前・パスの検索。
- スキャン中は取得済みの簡略マップを滑らかに更新。操作は「中止」のみです。
- エクスプローラーで開く、パスをコピー、ファイル1件を「ゴミ箱へ」「完全に削除」。削除は対象確認後に行います。

完全削除はごみ箱から戻せません。フォルダー・一括削除には対応しません。スキャンは通常ユーザーが読める範囲のメタデータを調べ、読めない場所・未走査・リンクの除外を区別して表示します。スキャン後の外部変更は、再スキャンで取得します。
